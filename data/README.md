# data/

Everything here except this file, `contract/` and `manifest.json` is ignored by git.
Download the test set from Google Drive (`2 Data/`) into this folder.

- `contract/label.jpg`, `contract/tray.jpg`: one sample photo each, used by the contract tests (committed)
- `manifest.json`: list of test photos and the expected result for each (committed)
- `medbag.db`, `photos/`: created by the server at run time
